# 📄 Lumina-Invoice-Generator

Generador de facturas profesional desarrollado con **React, TypeScript y Tailwind CSS**, diseñado para ofrecer una experiencia fluida de edición y una exportación a PDF con acabado de imprenta.

## 🚀 Características principales

* **Edición en Tiempo Real:** Visualiza los cambios en el diseño de la factura instantáneamente mientras editas los datos.
* [cite_start]**Cálculos Automáticos:** Gestión precisa de subtotales, IVA y totales finales sin errores manuales[cite: 21, 31, 32].
* **Exportación PDF Pixel-Perfect:** Motor de renderizado optimizado para mantener la jerarquía visual y evitar saltos de página innecesarios.
* [cite_start]**Diseño Corporativo:** Banner superior destacado, tablas organizadas y secciones claras para métodos de pago y notas legales[cite: 1, 2, 3, 35, 36].

## 🛠️ Stack Tecnológico

* **Framework:** React + Vite
* **Lenguaje:** TypeScript
* **Estilos:** Tailwind CSS
* **Arquitectura:** Componentes modulares (UI, Invoice, Layout)

## 📂 Estructura del Proyecto

El proyecto sigue una estructura limpia y escalable:
* `src/components`: Componentes reutilizables de la interfaz y la factura.
* `src/services`: Lógica de exportación a PDF.
* `src/store`: Gestión de estado global de la factura.
* `src/utils`: Formateadores de moneda y cálculos lógicos.
